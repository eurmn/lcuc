## 1. Storage Location & Ownership

All SQLite databases are isolated under `%LOCALAPPDATA%\lcu-companion\`:
- **`global-aram.db`**: Multi-worker crawled global ARAM dataset, participant facts, discovered PUUIDs, and crawler configuration.
- **`agent.db`**: Current player's personal match history, build facts, synced rune pages, and app configuration.

---

## 2. Live Database Size Metrics (October 2026 Snapshot)

### A. Total Database File Sizes
- **`global-aram.db`**: **325.08 MB** (340,873,216 bytes)
- **`agent.db`**: **0.52 MB** (540,672 bytes)

---

### B. Global Dataset (`global-aram.db`) Sizing & Entry Breakdown

| Table | Row Count | Description |
| :--- | :--- | :--- |
| `aram_games` | **5,533** | Unique collected ARAM: Mayhem games |
| `aram_participants` | **55,312** | Participant facts (10 players per game) |
| `discovered_accounts` | **37,302** | Summoner PUUIDs queue for crawler |
| `config` | **6** | Crawler worker count, game limits, and flags |
| `statistics_projections` | Dynamic | Pre-aggregated augment/item synergy projections |

#### Average Size Per Entry:
1. **Raw Detail JSON**:
   - Total text in `aram_games.detail_json`: **165.43 MB**
   - Average raw JSON per game: **30.37 KB** (31,103 bytes)
2. **Total Effective Database Footprint Per Game**:
   - Total DB size / `aram_games`: **59.69 KB** (61,121 bytes) per game
   - *Includes the raw JSON payload, normalized game attributes, 10 indexed participant rows, account links, and SQLite B-tree pages.*
3. **Effective Footprint Per Participant**:
   - Total DB size / `aram_participants`: **6.11 KB** (6,114 bytes) per participant entry
4. **Effective Footprint Per Discovered Account**:
   - Total DB size / `discovered_accounts`: **9.07 KB** per account entry
