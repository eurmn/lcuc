# RIOT LIVE CLIENT DATA IN-GAME API

## Protocol & Endpoint
- Base URL: `https://127.0.0.1:2999/liveclientdata/allgamedata`
- Transport: HTTPS with self-signed certificate (must skip TLS certificate verification).
- Availability: Port 2999 opens only when `League of Legends.exe` match is actively in progress.
- Mode Support: Supported across Summoner's Rift, ARAM, Arena, and ARAM: Mayhem.

## Relevant Sub-endpoints
- `/liveclientdata/activeplayer` -> Fast polling for current gold and level.
- `/liveclientdata/playeritems?riotId={riotId}` -> Specific player inventory without full dump.
- `/liveclientdata/eventdata` -> Event log for recent item purchases, kills, and objectives.
